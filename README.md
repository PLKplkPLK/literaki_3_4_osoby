# literaki_3_4_osoby

Literaki, ale na więcej niż 2 osoby.

[Dostępne tutaj.](https://kacpermuller.pl/literaki.php)

## Self-hosted

Wrzuć plik literaki.php na jakikolwiek serwer.

## Deployment

W systemie Windows ustaw w `.env` zmienne `VM_USER`, `VM_HOST` i `VM_LITERAKI_PHP_FILE_PATH`, a następnie uruchom:

```powershell
.\deploy.ps1
```
